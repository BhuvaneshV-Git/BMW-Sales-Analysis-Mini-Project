# BMW Sales Analysis
## README Summary

## Overview
Analyse BMW vehicle and sales records using Excel and Power BI to explore sales trends, regional performance, model comparisons, and vehicle characteristics. The report describes a CSV dataset covering 2010–2024.

## Objectives
- Analyse yearly sales trends and regional sales distribution.
- Compare vehicle models and identify top-performing models and markets.
- Explore fuel type, transmission, colour, and mileage patterns.
- Examine revenue by year, model, and region.
- Present the analysis through interactive dashboards to support data-driven decisions.

## Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables
- Power BI
- DAX calculated columns
- Data modelling and dashboard design

## Dashboard Preview

### Sales Overview
- Yearly sales comparison
- Region-wise sales contribution
- Sales distribution across models

### Vehicle & Preference Analysis
- Mileage analysis
- Sales performance by fuel type
- Colour preferences across models
- Sales performance matrix by model and month

### Revenue & Engine Analysis
- Revenue by year and model
- Revenue by region
- Mileage-based engine analysis

## Key Findings
- The preparation process records removal of 20 duplicate values.
- Missing values were filled using formulas, and data formats were standardised.
- Data was organised into Order Details, Sales Details, and Product Details.
- Calculated columns combined Fuel and Transmission and calculated revenue per order.
- Numerical sales and revenue findings are not provided in the report text.
- The analysis period needs confirmation: the report states 2010–2024, the filename refers to 2021–2024, and preprocessing mentions the last five years.
